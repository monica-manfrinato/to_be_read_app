# 📚 Virando a Página - TBR App

Projeto integrador focado em **Persistência de Dados** para dispositivos móveis, desenvolvido para ajudar leitores a organizarem sua fila de leitura, registrarem o progresso e avaliarem suas obras favoritas.

---

## 🚀 Funcionalidades

- **Cadastro de Livros:** Adicione novos livros à sua lista de leitura ("To Be Read").
- **Acompanhamento de Leitura:** Registre a data de início e a data de término de cada livro.
- **Sistema de Avaliação:** Atribua notas e opiniões sobre as obras concluídas.
- **Persistência Local:** Garantia de que os dados ficam salvos no dispositivo mesmo após fechar o aplicativo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem/Framework:** React Native
- **Ambiente de Execução:** Node.js
- **Gerenciadores de Pacotes:** npm / npx
- **Persistência de Dados:** AsyncStorage

---

## 💻 Como Rodar o Projeto

### Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [npm](https://www.npmjs.com/) (instalado junto com o Node)
- Emulador Android/iOS configurado ou o aplicativo **Expo Go** no seu dispositivo móvel (caso utilize Expo).

### Passo a Passo

1. **Clonar o repositório:**

   ```bash
   git clone https://github.com/monica-manfrinato/to_be_read_app.git
   cd to_be_read_app
   ```

2. **Instalar as dependências:**

   ```bash
   npm install
   ```

3. **Iniciar o Metro Bundler / Servidor Local:**

   ```bash
   npx expo start
   ```

4. **Visualizar no dispositivo:**

- Abra o aplicativo Expo Go no celular e escaneie o QR Code exibido no terminal.
- Alternativamente, pressione a no terminal para rodar no emulador Android ou w para rodar na Web.
